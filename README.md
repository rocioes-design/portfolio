# Rocío Espinosa portfolio

A TypeScript + Next.js rebuild of the Framer portfolio, ready for Vercel.

## Deploy

1. Create a Git repository from this folder and push it to GitHub.
2. Import that repository at [vercel.com/new](https://vercel.com/new).
3. Vercel detects Next.js automatically. Leave the default build settings and deploy.

For local development, run `npm install`, followed by `npm run dev`. If PowerShell reports that script execution is disabled, use `npm.cmd install` and `npm.cmd run dev` instead; this is the command form that works without changing PowerShell's security policy.
